## Published Papers

### 1. Scaling Full-Stack Applications in High-Compliance Environments: Architectural Patterns and Lessons from Healthcare and Finance Systems

**Author:** Sai Kumar Jee Bomule
**Date:** May 2026
**Status:** IEEE Software (under review) · SSRN Preprint

**Abstract:**
Scaling web applications in healthcare and financial services presents challenges that extend beyond typical performance engineering. This paper examines five architectural patterns that address competing constraints of regulatory compliance (HIPAA, SOX, PCI-DSS) and scalability — drawing on practical experience from production systems in the payments and healthcare industries.

**Patterns covered:**
- Compliance-aware database read scaling
- Stateless service design with externalized session state
- Circuit breaker implementation for dependent service failures
- Event-driven architecture for audit trail integrity
- API gateway as compliance enforcement layer
